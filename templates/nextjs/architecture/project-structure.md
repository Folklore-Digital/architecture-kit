# Project Structure

## Purpose

Explain App Router layout, route groups, shared components, and lib folders.

## Top-Level Layout

| Path | Purpose |
| --- | --- |
| `/app` | App Router routes, layouts, and route groups |
| `/components` | Shared UI components |
| `/lib` | Utilities, data clients, schemas |
| `/public` | Static assets |
| `/docs` | Architecture documentation |

## Route Groups

Document route groups, layouts, and special files (`layout.tsx`, `page.tsx`, `loading.tsx`, `error.tsx`).

## Change Rules

Update when adding route groups, major folders, or changing folder conventions.
