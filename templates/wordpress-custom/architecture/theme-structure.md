# Theme Structure

## Purpose

Explain theme folder layout, template hierarchy, and asset pipeline.

## Layout

| Path | Purpose |
| --- | --- |
| `resources/views` | Blade/Twig templates |
| `app/` | Controllers, filters, setup |
| `resources/scripts` | JS entry points |
| `resources/styles` | CSS/SCSS entry points |

## Change Rules

Update when theme structure or build entries change.
